Bienvenue sur le code source de mon portfolio !

## 🚀 À propos de ce projet
Ce dépôt contient le code source de ma page vitrine de portfolio. Le site est développé en `HTML`, `CSS` et `JavaScript` purs (Vanilla), conçu pour offrir une expérience fluide, avec un design sombre premium, un curseur personnalisé et des micro-animations au défilement.

## 🛠️ Stack Technique du Portfolio
- **HTML5** : Structure du document.
- **CSS3** : Variables, Flexbox/Grid, animations sur-mesure, effet "bruit" (noise overlay).
- **JavaScript** : Curseur interactif, API IntersectionObserver pour révéler les éléments au scroll.
- **Typographie** : *Syne*, *Playfair Display*, et *JetBrains Mono*.

## 💻 Mes Compétences Techniques 
- **Frontend** : React.js, Next.js, Tailwind CSS
- **Backend** : Java Spring Boot, Node.js, API REST
- **Base de données** : PostgreSQL, MySQL, SQL
- **Outils** : Git, GitHub, Postman, VS Code
